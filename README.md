# Forkcast

Can't decide what to eat? Enter a ZIP code (or use your location), pick what you're craving, set delivery and pickup distances and a max price, and let Forkcast choose a nearby place for you.

- Restaurant data comes from OpenStreetMap (Nominatim for quick results, Overpass for the full list).
- Prices are estimates per person based on the type of food and venue, since most listings don't publish menus.
- Works on phones; add it to your home screen from the browser's Share or menu button.
